# ORBIT(オービット)

「AIチームメイトが1つのワークスペースで働く」をコンセプトにした、ポートフォリオ用のコンセプトサイト+動くデモアプリです。ビルド不要の完全な静的サイトで、GitHub Pagesなど任意の静的ホスティングでそのまま公開できます。

> ※ ORBITは架空のサービスです。名称・文言・デザイン・コードはすべてオリジナルで、他社サービスのロゴ・画像・ブランドは使用していません。

## 構成

```
orbit/
├── index.html        # ランディングページ(LP)
├── app/
│   └── index.html    # 動作するデモアプリ(ワークスペース)
├── assets/
│   ├── style.css     # 共通CSS(LP・アプリ共通のデザイン言語)
│   └── app.js        # アプリのロジック(オーケストレーション/デモモード)
└── README.md
```

すべてのリンク・アセットは相対パスで記述しているため、サブディレクトリ(例: `/For-Instinct-and-MistralCode/orbit/`)に置いてもそのまま動きます。

## 使い方

### 1. LPを開く

`orbit/index.html` を開くと、コンセプト・使い方・特徴を確認できます。

### 2. アプリを開く

「アプリを開く」ボタン、または `orbit/app/` からワークスペースに入ります。

- **目標を入力して「チームを動かす」** を押すと、オーケストレーターが目標を3〜4個の役割タスクに分解し、エージェントカードが生成されます
- 各エージェントが順番に担当タスクを実行し、前のメンバーの出力を引き継ぎながら、結果をチャットタイムラインに投稿します
- 最後にまとめ役が全体を統合して **成果物カード** を表示します
- 成果物カードの **「承認する」** を押すと承認済みになり、 **Markdownをダウンロード** で成果物を `.md` ファイルとして保存できます

### 3. デモモードとAPI接続

| モード | 条件 | 動き |
|---|---|---|
| デモモード(既定) | APIキー未設定 | スクリプト化されたダミー応答で、実際の実行と同じ流れを体験できます。画面に「デモモード」バッジが常に表示されます |
| API接続 | Mistral APIキー設定済み | Mistral API(`mistral-small-latest`)で実際のLLMが目標の分解・各エージェントの実行・成果物の統合を行います(ストリーミング表示対応) |

### 4. APIキーの設定

1. ヘッダーの「APIキー設定」を開く
2. [https://console.mistral.ai/](https://console.mistral.ai/) で取得したAPIキーを貼り付けて保存

**セキュリティについて**

- 入力したAPIキーは **お使いのブラウザの localStorage にのみ保存** されます
- キーは **`https://api.mistral.ai` へのAPIリクエスト以外には絶対に送信されません**(外部サーバー・アナリティクス等への送信は一切ありません)
- キーを削除すれば即座にデモモードへ戻ります

## エラーメッセージについて

API実行時の主なエラーは日本語で画面に表示されます。

| 状況 | 表示 |
|---|---|
| 401 / 403 | APIキーが無効です。設定を確認してください |
| 402 | Mistralのクレジット不足です |
| 429 | リクエスト制限中です。少し待ってから再試行してください |
| 5xx / ネットワーク | サーバーエラー・接続エラーの案内 |

## デザイン方針

- 白基調・余白たっぷりのミニマルなUI
- グラデーション不使用。単色のみ(アクセントは `#0666EB` の1色、ほかに `#0B0B0F`・グレー系・白)
- フォント: `"Inter", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif`
- 角丸16〜24px・1pxボーダーのカード、ピル型ボタン、控えめなフェードインのみのアニメーション
- モバイル完全対応(エージェント一覧とチャットは縦積みに切り替わります)
