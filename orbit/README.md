# ORBIT(オービット)

「AIチームメイトが1つのワークスペースで働く」をコンセプトにした、ポートフォリオ用のコンセプトサイト+動くデモアプリです。ビルド不要の完全な静的サイトで、GitHub Pagesなど任意の静的ホスティングでそのまま公開できます。

> ※ ORBITは架空のサービスです。名称・文言・デザイン・コードはすべてオリジナルで、他社サービスのロゴ・画像・ブランドは使用していません。

## 構成

```
orbit/
├── index.html        # ランディングページ(LP)
├── app/
│   └── index.html    # 動作するデモアプリ(ワークスペース)
├── assets/
│   ├── style.css     # 共通CSS(LP・アプリ共通のダーク/ライトテーマ)
│   └── app.js        # アプリのロジック(オーケストレーション/SSE/デモモード/セッション)
└── README.md
```

すべてのリンク・アセットは相対パスで記述しているため、サブディレクトリ(例: `/For-Instinct-and-MistralCode/orbit/`)に置いてもそのまま動きます。

## ランディングページ(LP)

- 近黒(#0A0A0A)ベースの静かなヒーロー。巨大な中央見出し「AIチームを、ひとつの場所に。」の直下に**ピル型の入力欄**があり、入力して送信すると入力内容を `?goal=` パラメータで引き継いだままアプリ(`/app/`)に遷移します
- 極小ナビ(ロゴ / 使い方 / アプリを開く)と、同じ大きさの1pxボーダーカード3枚(角丸24px)の「使い方」3ステップ
- ヘッダーのトグルでライトテーマにも切替可能(設定はlocalStorageに保存)

## アプリ(/app/)

ChatGPT型のレイアウトです。

- **左サイドバー**: ORBITロゴ、「新しいチーム」ボタン、過去のセッション履歴(localStorageに最大20件保存)。下部にAPIキー設定とテーマ切替。モバイルではハンバーガーで開閉
- **中央1カラム(max-width 720px)**: 空の状態は「何を成し遂げたい?」の大きな見出し+ピル型コンポーザー+提案ピル3つ。送信すると会話ビューに切り替わります
- **会話**: ユーザー発言は右寄せのグレー丸角バブル。エージェントの返信は吹き出しなしでアバター(単色円+頭文字)+名前+ストリーミング本文。「考え中…」は3点パルス
- **計画カード**: 目標の作業分担(プランナー/リサーチャー/ライター/レビュアー/まとめ役の5タスク)を折りたたみ可能な小さなカードで会話内に表示。各エージェントのステータス(待機/作業中/完了)がリアルタイムに更新されます
- **成果物カード**: まとめ役が全体を統合した成果物を会話内のカードで表示。「承認する」(アクセント色ピル)で控えめなチェック表示、「Markdownをダウンロード」で `.md` ファイルとして保存
- **コンポーザーは常に画面下に固定**。実行中は送信ボタンが**停止ボタン**に変わり、途中で中断できます
- **テーマ**: 既定はOS設定(`prefers-color-scheme`)に追従。サイドバー下部のトグルでダーク(近黒)/ライト(白)を切替可能
- **デモモード**: APIキー未設定でもスクリプト化されたダミー応答で同じ流れをすべて体験できます。画面には「デモモード」バッジが常に表示されます

### 実行の流れ

1. 目標を入力して送信すると、オーケストレーターが目標を3〜4個の役割タスクに分解
2. 各エージェントが順番に担当タスクを実行し、前のメンバーの出力を引き継ぎながらチャットに投稿(ストリーミング表示)
3. 最後にまとめ役が成果物カードを生成。承認してMarkdownをダウンロード

### デモモードとAPI接続

| モード | 条件 | 動き |
|---|---|---|
| デモモード(既定) | APIキー未設定 | スクリプト化されたダミー応答で、実際の実行と同じ流れを体験できます |
| API接続 | Mistral APIキー設定済み | Mistral API(`mistral-small-latest`)で目標の分解・各エージェントの実行・成果物の統合を行います(`stream: true` のストリーミング表示対応) |

### APIキーの設定

1. サイドバー下部の「APIキー設定」を開く
2. [https://console.mistral.ai/](https://console.mistral.ai/) で取得したAPIキーを貼り付けて保存

**セキュリティについて**

- 入力したAPIキーは **お使いのブラウザの localStorage にのみ保存** されます
- キーは **`https://api.mistral.ai` へのAPIリクエスト以外には絶対に送信されません**(外部サーバー・アナリティクス等への送信は一切ありません)
- キーを削除すれば即座にデモモードへ戻ります

### エラーメッセージ

| 状況 | 表示 |
|---|---|
| 401 / 403 | APIキーが無効です。設定を確認してください |
| 402 | Mistralのクレジット不足です |
| 429 | リクエスト制限中です。少し待ってから再試行してください |
| 5xx / ネットワーク | サーバーエラー・接続エラーの案内 |

## デザイン方針

- ChatGPT型のワークスペース構成+Grok型の静かなLP構成を、独自の文言・コードで表現
- システムフォントのみ(日本語は Hiragino Kaku Gothic ProN / Noto Sans JP にフォールバック)。外部フォント読み込みなし
- グラデーション・グロー・ネオン不使用。単色のみ。アクセントは `#0666EB` の1色、他は `#0B0B0F`・グレー系・白
- 影はほぼなし。1pxのヘアラインボーダー、角丸12〜24pxとピル型
- アニメーションはフェードと高さ変化程度のみ
- ダーク/ライト両テーマ対応。375px〜1440pxのレスポンシブ(モバイルではサイドバーがオフキャンバスに)
